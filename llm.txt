# Tray.jl

Tray is an ordered leaf array with a balanced aggregation index in Julia.

## Current repository state

This is an implemented Julia library. All epics are complete, all 73 tickets
are closed. The codebase includes:

- Core tree (balanced n-ary, range query, insert/remove/update, reweight)
- ScalarSummary, AttributionPayload, SamplePayload, AlignedArrayPayload
- SnapshotEpoch (MVCC snapshots), DashboardModel (reactive viewport)
- FinancialRisk adapter (VaR, expected shortfall, Gaussian/component/marginal)
- Compiler IR incrementalization (optional IRTools-based derive)
- Persistence (save_tree/load_tree with binary format and checksums)
- 46 Espectacular contracts mapping specs to tests

## Workflow and governance

The repository uses:
- `wai` for research, rationale, and handoffs

- OpenSpec for change proposals and capability specifications

## Preferred commands

Use the repo `justfile`:
- `just test` — run all Julia tests
- `just test-file <pattern>` — focused @testitem blocks
- `just fmt` — format with JuliaFormatter
- `just pretender-check` — structural code quality scan
- `just test-select` — testaruda test selection
- `just ci` — full CI pipeline (fmt-check, test, spell-check, doc-check)

## Important constraints

- Julia 1.12+ only
- ReTestItems for testing (single-file convention in test/runtests.jl, ~8800 loc)
- IRTools is optional (not a hard dependency — loaded lazily for incrementalization)
- Financial risk adapter is optional (loads on demand)
- Preserve EARS IDs REQ-1–REQ-44 and REQ-A1–REQ-A17
- No LLVM, differential dataflow, or memoization — these are explicit non-goals
